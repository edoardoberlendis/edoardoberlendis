By day I'm a consultant and by night and on weekends I build Python tools to test investment ideas, because a good-looking idea is just a hypothesis until it survives a backtest.

**What I've learned so far**

- Most chart patterns don't work. I tested nine and eight failed.
- My trading bot found a real edge, then transaction costs found it too. Limit orders won some of it back.
- The most useful number in a backtest is usually the max drawdown, not the return.
